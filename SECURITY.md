# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not publish sensitive security details in a public issue. Use GitHub's private security reporting feature if it is enabled for this repository.

Never include passwords, API keys, access tokens, payment information, or personal data in an issue.

## Data handling

The current desktop application processes selected files locally. It does not require an account or send spreadsheet contents to a remote service by default.
