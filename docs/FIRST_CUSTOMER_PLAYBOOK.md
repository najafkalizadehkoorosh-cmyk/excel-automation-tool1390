# First Customer Playbook

## Ideal early users

Look for small teams or freelancers who repeatedly receive messy CSV/Excel exports and spend time cleaning or combining them.

## Demo

1. Show `examples/customer_contacts_sample.csv`.
2. Run Customer Contacts preset.
3. Open the generated quality report.
4. Show that the duplicate row and inconsistent formatting are handled deterministically.
5. Ask which real recurring spreadsheet task they have.

## Discovery conversation

Do not start by promising savings. Ask about the current workflow and frequency first.

Useful questions:

- How many files do you process each week?
- Which steps are repeated manually?
- Which errors happen most often?
- What output must be delivered to the next system?
- Which part would you most like to automate?

## Conversion signal

A strong validation signal is a user describing a recurring task and asking for a specific feature or workflow preset.

## Safety

Use only synthetic or user-authorized sample data. Do not ask prospects to send confidential customer databases through public channels.
