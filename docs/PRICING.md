# Pricing Experiment

This document is an experiment, not a published price list.

## Suggested validation offers

### Free
- Single-file cleanup
- Basic quality report
- Core transformations
- Limited batch/merge usage

### Pro candidate
- More workflow presets
- Larger batch jobs
- Advanced quality reporting
- Custom reusable rules

### Pricing test

Test a small number of simple price points only after users demonstrate repeated value. Example hypotheses can be $5/month, $10/month, or a small one-time purchase, but none should be presented as final pricing until validated.

## Goal

The initial business target is $50/month. This is a milestone for validation, not a promise or forecast.

Do not add payment infrastructure until a lawful provider and seller eligibility have been verified.
