# Zero-Cost Launch Checklist

## Product
- [x] Windows Release Candidate 0.5.1 builds in GitHub Actions.
- [x] Smoke test runs during Windows build.
- [x] Quick start exists.
- [x] Beta guide exists.
- [x] Product listing copy exists.
- [x] Pricing experiment exists.
- [x] Privacy and terms drafts exist.

## Distribution
- [x] Public GitHub repository is available.
- [x] Static landing page exists under `docs/index.html`.
- [x] Synthetic demo data exists.
- [ ] Published GitHub Release with the EXE attached.

## Commercial
- [x] Free/Pro boundary documented.
- [x] Sales funnel documented.
- [x] Zero-budget outreach copy documented.
- [ ] Lawful seller account/payment route selected by an eligible account holder.
- [ ] Final storefront published.

## Important boundary

The current public repository is MIT-licensed. The current public code should not be advertised as exclusive software. A future proprietary edition must be made from genuinely new commercial material and use a separately reviewed licensing/distribution model.

## Cost

Current project spend target: $0. No paid service is required for the desktop MVP or for basic GitHub-based distribution.
