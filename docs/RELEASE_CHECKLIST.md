# Release Checklist

## Technical

- [ ] CI is green on the release commit.
- [ ] Windows executable builds successfully.
- [ ] Fresh Windows machine test completed.
- [ ] CSV, XLSX and XLSM workflows tested with representative samples.
- [ ] Batch and merge workflows tested.
- [ ] Important output files manually reviewed.
- [ ] No secrets or private test data are committed.

## Product

- [ ] README and quick start are current.
- [ ] Landing page is current.
- [ ] Version number is consistent.
- [ ] Known limitations are documented.

## Legal and distribution

- [ ] Privacy policy reviewed.
- [ ] Terms reviewed.
- [ ] Distribution channel requirements reviewed.
- [ ] Payment provider requirements reviewed before accepting money.

## Cost control

- [ ] No paid service is enabled without explicit approval.
- [ ] No domain or advertising purchase is made without explicit approval.

## Launch

- [ ] Release notes published.
- [ ] Download instructions verified.
- [ ] Customer support/feedback path prepared.
