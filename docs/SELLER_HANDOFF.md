## What a seller must still do

1. Choose a lawful storefront/payment route supported in the seller's country and for the seller's age/status.
2. Complete that provider's account, identity, tax, and payout setup through its official interface.
3. Use only the product description and pricing actually approved for the final offer.
4. Upload the Windows build and verify the customer download flow.
5. Publish the storefront only after reviewing applicable consumer, tax, privacy, and software-license requirements.

## Important licensing boundary

The public repository is MIT-licensed. Do not describe the current public code as exclusive or proprietary. Any future proprietary edition must contain genuinely new commercial material and use a separately reviewed licensing/distribution model.

## Security

Never put bank details, passwords, payment tokens, API keys, private signing keys, or other secrets into the repository.

## No-cost rule

Do not buy a domain, advertising package, paid hosting, paid API, analytics service, or subscription unless separately approved. The current desktop MVP does not require paid infrastructure.
