# Zero-Cost Launch Checklist

## Product

- [x] Windows executable builds in GitHub Actions.
- [x] Core workflows implemented.
- [x] Synthetic demo data included.
- [x] Quick start documentation included.
- [x] Landing page included.
- [x] Privacy and terms drafts included.

## Free distribution

- [ ] Publish a reviewed GitHub Release for the chosen version.
- [ ] Verify the download and execution path from a clean Windows environment.
- [ ] Share the project only in communities that allow relevant self-promotion.
- [ ] Collect feedback from early users before adding paid infrastructure.

## Sales validation

- [ ] Identify a narrow customer problem.
- [ ] Track qualified conversations and demo/download results manually.
- [ ] Ask what task users repeat and what outcome they would pay for.
- [ ] Add only repeatedly requested premium capabilities.

## Payment

- [ ] Choose a lawful payment provider supported in the seller's jurisdiction.
- [ ] Complete any required age/identity/account verification through the provider.
- [ ] Verify fees, payout rules, refunds, taxes, and digital-product requirements.

Do not treat this checklist as legal, tax, or financial advice.
