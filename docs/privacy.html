Privacy Policy

Pre-release policy. This page describes the current desktop MVP and should receive legal review before commercial launch.

Local processing

The current desktop application processes selected spreadsheet files locally on the user's computer. The application does not require a hosted upload service for its core workflows.

Data collection

The current desktop MVP does not intentionally collect account, payment, analytics, or spreadsheet-content data through a hosted backend.

Future services

If online accounts, payments, analytics, telemetry, cloud processing, or support systems are added, the applicable data practices will be documented and this policy updated before release.

User responsibility

Users should only process data they are authorized to use and should avoid placing confidential information in public support channels.

Contact and deletion

The current desktop MVP has no hosted user account database to delete. A contact and account-deletion process must be added before any account-based service launches.
