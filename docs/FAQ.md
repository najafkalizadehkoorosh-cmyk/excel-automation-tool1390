# FAQ

## Does the tool upload my spreadsheet?

The current desktop MVP is local-first. Core processing runs on the user's computer and does not require a hosted upload service.

## What files are supported?

CSV, XLSX, and XLSM are supported by the current MVP.

## What can it do?

It can clean common spreadsheet problems, inspect data quality, apply deterministic transformations, process folders in batch, merge files, and produce quality reports.

## Will it change my business data?

The built-in transformations are deliberately conservative. The tool should not invent missing values. Users should still review important outputs before using them in production.

## Who is it for?

It is aimed at people and small teams who repeatedly receive or produce spreadsheet exports and spend time cleaning, standardizing, or combining them.

## Is there a cloud account?

Not for the current desktop MVP.

## Is there a free version?

The current MVP can be used as the validation build. Any future paid tier should be defined only after real user feedback identifies a valuable premium capability.

## Can I use it for commercial data?

Users are responsible for having the right to process their files and for reviewing outputs before production use.

## What about sensitive data?

Because the core workflow is local-first, users do not need to upload spreadsheet contents to a hosted service. Users should still follow their organization's security rules and keep backups.
