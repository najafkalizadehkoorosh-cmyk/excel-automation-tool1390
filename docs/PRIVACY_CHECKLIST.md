# Pre-release Privacy Checklist

This project is currently a local-first desktop MVP.

Before public commercial release, verify:

- [ ] The final application behavior matches the privacy policy.
- [ ] No spreadsheet contents are uploaded without explicit user action and notice.
- [ ] No analytics or telemetry is enabled without documented purpose and consent where required.
- [ ] Any future third-party service is documented before use.
- [ ] A user-facing support/contact method is available.
- [ ] A practical account/data deletion process exists if accounts are introduced.
- [ ] Applicable privacy and consumer laws have been reviewed for the intended markets.

Do not treat this checklist as legal advice.
