# Zero-Cost Product Metrics

Track these manually during validation:

- Downloads: how many people obtain the app
- Activated users: how many successfully complete one workflow
- Repeat users: how many return and process another file later
- Qualified prospects: users with a recurring spreadsheet task
- Paid interest: users who ask for or endorse a specific premium feature
- Customers: completed lawful purchases
- Monthly revenue: actual collected revenue after applicable fees/refunds

## Decision rules

- If downloads are low, improve distribution and positioning before adding features.
- If activation is low, improve onboarding and reliability.
- If activation is good but paid interest is low, improve the target problem or offer.
- If users repeatedly request the same capability, prioritize that capability for the next paid experiment.

Do not collect personal data solely for analytics during this zero-cost validation phase.
