# Listing Copy — Excel Automation Tool

## Product title

Excel Automation Tool — Clean, Standardize & Batch-Process Excel/CSV Files

## One-line description

A lightweight Windows tool for cleaning, inspecting, standardizing, batch-processing, and merging recurring Excel/CSV files locally.

## Long description

Still cleaning the same spreadsheet exports every week?

Excel Automation Tool turns repeatable spreadsheet chores into a simple local workflow. Select a CSV/XLSX/XLSM file or folder, choose a workflow, run it, and review the output.

### Useful for

- recurring customer/contact exports;
- sales and operations exports;
- vendor and supplier files;
- duplicate cleanup;
- inconsistent column names and text formatting;
- combining multiple CSV/Excel files;
- recurring batch cleanup jobs.

### Included workflows

- General Cleanup
- Customer Contacts
- Sales Export
- Single-file processing
- Folder batch processing
- File merge
- Data-quality inspection
- HTML/JSON quality reports

### Privacy-oriented design

The current desktop MVP is local-first. Core processing does not require uploading spreadsheet contents to a hosted service.

### Important

This is a pre-release MVP. Users should review important outputs before relying on them in production systems. Product performance and savings are not guaranteed.
