# Zero-Cost Distribution Stack

The current MVP is designed to be operated without paid infrastructure.

## Included free assets

- GitHub repository for source and documentation
- GitHub Actions for automated tests and Windows builds
- GitHub Release workflow for tagged Windows builds
- Local-first desktop processing
- Static product landing page in `docs/index.html`
- Synthetic demo data in `examples/`

## Cost rule

Do not activate paid hosting, domains, analytics, advertising, APIs, or payment services without explicit approval.

## What still needs a human

A lawful payment/distribution provider may require the seller to complete account setup, identity/age checks, tax information, or other verification. Those steps must be completed by the account holder through the provider's official interface.
