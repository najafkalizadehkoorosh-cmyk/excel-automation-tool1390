# Product Listing — Excel Automation Tool

## Title
Excel Automation Tool — Clean, Standardize, Batch-Process & Merge CSV/Excel Files

## One-line description
A local-first Windows utility that turns repetitive spreadsheet cleanup into repeatable workflows.

## What the buyer gets

- Windows desktop application
- CSV/XLSX/XLSM support
- General cleanup workflow
- Customer/contact cleanup workflow
- Sales export workflow
- Batch processing
- File merging with optional source tracking
- Data-quality reports in HTML/JSON
- Quick-start documentation

## Best fit

For small teams and individuals who repeatedly clean spreadsheet exports from CRMs, marketplaces, vendors, sales systems, or internal tools.

## Core benefit

Spend less time repeating the same spreadsheet cleanup steps and more time using the cleaned data.

## Trust & privacy positioning

Core desktop processing is local-first. The MVP does not require uploading spreadsheet contents to a hosted service for its main workflows.

## Current product status

Release Candidate 0.5.1. Review important outputs before production use. The product is not marketed as guaranteed accurate and is not a compliance certification.
