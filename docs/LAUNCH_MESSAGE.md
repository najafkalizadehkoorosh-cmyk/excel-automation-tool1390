# Launch Message

## English

Excel Automation Tool is a lightweight Windows app for repetitive spreadsheet work. Clean and standardize CSV/Excel data, inspect quality problems, process folders in batch, and merge exports — with the core workflow running locally on your computer.

Use the included synthetic example to test the product safely.

## Positioning

Best for small teams, freelancers, operations staff, and analysts who repeat the same spreadsheet cleanup or file-processing work.
