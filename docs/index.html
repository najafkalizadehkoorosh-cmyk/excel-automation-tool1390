Excel Automation Tool

Turn messy spreadsheets into usable data.

Clean, inspect, transform, batch-process and merge Excel/CSV files from a simple Windows application. Core processing is designed to stay local on the user's machine.

View the project on GitHub

Clean
Remove empty rows/columns, trim text and duplicates.
Inspect
Find missing values, duplicates and likely invalid emails.
Transform
Normalize column names, text and email fields.
Batch
Process supported files in a folder automatically.
Merge
Combine multiple files into one structured output.
Local-first
No upload service is required for core processing.

Designed for small teams

Start with repeatable spreadsheet chores and reduce manual cleanup. Always review important outputs before using them in production systems.
