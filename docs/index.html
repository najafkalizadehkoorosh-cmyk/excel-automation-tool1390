Turn repetitive spreadsheet work into a simple workflow.

What it does

Clean
Remove empty rows/columns, trim whitespace and remove duplicate rows.
Inspect
Profile missing values, duplicates, repeated values, empty text and likely invalid emails.
Transform
Normalize column names, text and likely email fields with deterministic rules.
Batch
Apply the same workflow to a folder of supported files with per-file error isolation.
Merge
Combine multiple supported files and optionally retain source-file information.
Local-first
Core desktop processing runs locally; no hosted upload service is required.

Simple workflow

1. Select a CSV/XLSX/XLSM file or folder.

2. Choose Clean, Batch, or Merge.

3. Run the deterministic workflow.

4. Review the output and quality information.
